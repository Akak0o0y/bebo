# Bebo introduction film

[Watch the 45-second introduction](Bebo-45s.mp4) · [English subtitles](Bebo-45s.srt)

1920 × 1080, 30 fps, H.264 video with stereo AAC audio. The revised soundtrack uses **David — The Movie Trailer**, generated with ElevenLabs Eleven v3, plus an original ElevenLabs Music v2 instrumental. The narration changes from a quiet opening to an excited demonstration and a deep closing line. Music lowers during speech. This soundtrack belongs to the film; Bebo's bundled application voice remains Kokoro.

The film combines animated presentation with screenshots of a controlled Bebo run. Bebo's actual Electron app created a local checklist, read it back, and its contents were verified. Model decisions were scripted. The large cursor and result card are editorial animation, and the phone is a UI preview. This is not a live-model or physical-iPhone performance benchmark.
